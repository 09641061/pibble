# Pibble class templates

The running example is the `customers` context: staff register a `Customer` by phone (C1, C3) with an idempotency key, read it back and delete it (C5). Copy a block, rename the nouns, and keep its package, annotations, and method names. Imports are omitted except where the import is the point.

```java
package com.takodu.api.customers.domain.model.valueobjects;

/** C1: E.164. WhatsApp sends "51987654321"; staff type "+51987654321". */
public record PhoneNumber(String e164) {
    private static final Pattern E164 = Pattern.compile("^\\+[1-9][0-9]{6,14}$");

    public PhoneNumber {
        if (e164 == null || e164.isBlank()) throw new IllegalArgumentException("Phone is required");
        e164 = e164.replaceAll("[\\s-]", "");
        if (!E164.matcher(e164).matches()) throw new IllegalArgumentException("Phone must be in E.164 format");
    }

    public static PhoneNumber fromWhatsappId(String waId) { return new PhoneNumber("+" + waId); }
}
```

```java
package com.takodu.api.customers.domain.model.aggregates;

/**
 * A person identified by a WhatsApp phone number within one organization (C1).
 */
@Getter
public class Customer {
    private final CustomerId id;
    private final OrganizationId organizationId;
    private final PhoneNumber phone;
    private String name;
    private String whatsappProfileName;
    private Instant deletedAt;
    private final IdempotencyKey idempotencyKey;

    /** C3: registered by staff; the phone is required, the name optional. */
    public static Customer registerByStaff(OrganizationId organizationId, PhoneNumber phone, String name,
                                           IdempotencyKey idempotencyKey) {
        return new Customer(null, organizationId, phone, blankToNull(name), null, null, idempotencyKey);
    }

    /** C2: created by the first inbound WhatsApp message; the webhook is deduplicated by wamid instead. */
    public static Customer fromWhatsapp(OrganizationId organizationId, PhoneNumber phone, String profileName) {
        return new Customer(null, organizationId, phone, null, blankToNull(profileName), null, null);
    }

    /** Rehydration constructor; only persistence assemblers call it. */
    public Customer(CustomerId id, OrganizationId organizationId, PhoneNumber phone, String name,
                    String whatsappProfileName, Instant deletedAt, IdempotencyKey idempotencyKey) {
        this.id = id;
        this.organizationId = Objects.requireNonNull(organizationId, "organizationId is required");
        this.phone = Objects.requireNonNull(phone, "phone is required");
        this.name = name;
        this.whatsappProfileName = whatsappProfileName;
        this.deletedAt = deletedAt;
        this.idempotencyKey = idempotencyKey;
    }

    /** C5: soft delete; the phone can be registered again afterwards. */
    public void delete(Instant now) {
        if (deletedAt != null) throw new CustomerAlreadyDeletedException(id);
        this.deletedAt = now;
    }

    /** Name staff see: the typed name, else the WhatsApp profile name, else the phone. */
    public String displayName() {
        if (name != null) return name;
        return whatsappProfileName != null ? whatsappProfileName : phone.e164();
    }

    private static String blankToNull(String value) {
        return value == null || value.isBlank() ? null : value.strip();
    }
}
```

## Application

```java
package com.takodu.api.customers.application.commandservices;

public interface CustomerCommandService {
    /**
     * @param command registration data
     * @return the saved customer, or the one an earlier request with the same key created
     * @throws CustomerAlreadyRegisteredException when an active customer has this phone (C1)
     */
    Customer handle(RegisterCustomerCommand command);

    /**
     * @throws AccessDeniedException when the caller's role cannot delete customers
     * @throws CustomerNotFoundException when no active customer has this id in the organization
     */
    Customer handle(DeleteCustomerCommand command);
}
```

```java
package com.takodu.api.customers.application.internal.commandservices;

@ApplicationScoped
public class CustomerCommandServiceImpl implements CustomerCommandService {
    private final CustomerRepository customerRepository;
    private final AccessPolicy accessPolicy;
    private final Clock clock;

    public CustomerCommandServiceImpl(CustomerRepository customerRepository, AccessPolicy accessPolicy, Clock clock) {
        this.customerRepository = customerRepository;
        this.accessPolicy = accessPolicy;
        this.clock = clock;
    }

    @Override
    @Transactional
    public Customer handle(RegisterCustomerCommand command) {
        var earlier = customerRepository.findByIdempotencyKey(command.organizationId(), command.idempotencyKey());
        if (earlier.isPresent()) return earlier.get();
        if (customerRepository.existsActiveByPhone(command.organizationId(), command.phone()))
            throw new CustomerAlreadyRegisteredException(command.phone());
        return customerRepository.save(Customer.registerByStaff(command.organizationId(), command.phone(),
                command.name(), command.idempotencyKey()));
    }

    @Override
    @Transactional
    public Customer handle(DeleteCustomerCommand command) {
        accessPolicy.require(Action.DELETE_CUSTOMERS);
        var customer = customerRepository.findActiveById(command.organizationId(), command.customerId())
                .orElseThrow(() -> new CustomerNotFoundException(command.customerId()));
        customer.delete(clock.instant());
        return customerRepository.save(customer);
    }
}
```

```java
package com.takodu.api.customers.infrastructure.persistence.jpa.repositories;

@ApplicationScoped
public class CustomerPersistenceRepository implements PanacheRepositoryBase<CustomerPersistenceEntity, UUID> {
    public Optional<CustomerPersistenceEntity> findActiveById(UUID organizationId, UUID id) {
        return find("organizationId = ?1 and id = ?2 and deletedAt is null", organizationId, id).firstResultOptional();
    }

    public Optional<CustomerPersistenceEntity> findByIdempotencyKey(UUID organizationId, UUID key) {
        return find("organizationId = ?1 and idempotencyKey = ?2", organizationId, key).firstResultOptional();
    }

    public boolean existsActiveByPhone(UUID organizationId, PhoneNumber phone) {
        return count("organizationId = ?1 and phone = ?2 and deletedAt is null", organizationId, phone) > 0;
    }
}
```

```java
package com.takodu.api.customers.infrastructure.persistence.jpa.assemblers;

public final class CustomerPersistenceAssembler {
    private CustomerPersistenceAssembler() { }

    public static Customer toDomainFromPersistence(CustomerPersistenceEntity entity) {
        return new Customer(new CustomerId(entity.getId()), new OrganizationId(entity.getOrganizationId()),
                entity.getPhone(), entity.getName(), entity.getWhatsappProfileName(), entity.getDeletedAt(),
                entity.getIdempotencyKey() == null ? null : new IdempotencyKey(entity.getIdempotencyKey()));
    }

    public static CustomerPersistenceEntity toPersistenceFromDomain(Customer customer) {
        var entity = new CustomerPersistenceEntity();
        entity.setId(customer.getId() == null ? null : customer.getId().value());
        entity.setOrganizationId(customer.getOrganizationId().value());
        entity.setPhone(customer.getPhone());
        entity.setName(customer.getName());
        entity.setWhatsappProfileName(customer.getWhatsappProfileName());
        entity.setDeletedAt(customer.getDeletedAt());
        entity.setIdempotencyKey(customer.getIdempotencyKey() == null ? null : customer.getIdempotencyKey().value());
        return entity;
    }
}
```

The adapter owns the translation of the constraints of its table into domain exceptions.

```java
package com.takodu.api.customers.infrastructure.persistence.jpa.adapters;

import org.hibernate.exception.ConstraintViolationException;

@ApplicationScoped
public class CustomerRepositoryImpl implements CustomerRepository {
    private static final String ACTIVE_PHONE_UNIQUE = "customers_phone_uk";
    private static final String IDEMPOTENCY_UNIQUE = "customers_idempotency_uk";

    private final CustomerPersistenceRepository customerPersistenceRepository;

    public CustomerRepositoryImpl(CustomerPersistenceRepository customerPersistenceRepository) {
        this.customerPersistenceRepository = customerPersistenceRepository;
    }

    @Override
    public Optional<Customer> findActiveById(OrganizationId organizationId, CustomerId customerId) {
        return customerPersistenceRepository.findActiveById(organizationId.value(), customerId.value())
                .map(CustomerPersistenceAssembler::toDomainFromPersistence);
    }

    @Override
    public Optional<Customer> findByIdempotencyKey(OrganizationId organizationId, IdempotencyKey idempotencyKey) {
        return customerPersistenceRepository.findByIdempotencyKey(organizationId.value(), idempotencyKey.value())
                .map(CustomerPersistenceAssembler::toDomainFromPersistence);
    }

    @Override
    public boolean existsActiveByPhone(OrganizationId organizationId, PhoneNumber phone) {
        return customerPersistenceRepository.existsActiveByPhone(organizationId.value(), phone);
    }

    @Override
    public Customer save(Customer customer) {
        var entity = CustomerPersistenceAssembler.toPersistenceFromDomain(customer);
        try {
            if (entity.getId() == null) {
                customerPersistenceRepository.persist(entity);
            } else {
                entity = customerPersistenceRepository.getEntityManager().merge(entity);
            }
            customerPersistenceRepository.flush();
        } catch (ConstraintViolationException e) {
            switch (e.getConstraintName()) {
                case ACTIVE_PHONE_UNIQUE -> throw new CustomerAlreadyRegisteredException(customer.getPhone());
                case IDEMPOTENCY_UNIQUE -> throw new RequestInProgressException(customer.getIdempotencyKey());
                case null, default -> throw e;
            }
        }
        return CustomerPersistenceAssembler.toDomainFromPersistence(entity);
    }
}
```

```java
package com.takodu.api.customers.interfaces.rest;

@Path("/api/v1/customers")
@Produces(MediaType.APPLICATION_JSON)
@Tag(name = "Customers", description = "Customers of the caller's organization")
public class CustomersController {
    private final CustomerCommandService customerCommandService;
    private final CustomerQueryService customerQueryService;
    private final TenantContext tenantContext;

    public CustomersController(CustomerCommandService customerCommandService,
                               CustomerQueryService customerQueryService, TenantContext tenantContext) {
        this.customerCommandService = customerCommandService;
        this.customerQueryService = customerQueryService;
        this.tenantContext = tenantContext;
    }

    @POST
    @Consumes(MediaType.APPLICATION_JSON)
    @ResponseStatus(201)
    @Operation(summary = "Register customer", description = "Registers a customer by phone in the caller's organization.")
    @APIResponse(responseCode = "201", description = "Customer registered",
            content = @Content(schema = @Schema(implementation = CustomerResource.class)))
    @APIResponse(responseCode = "400", description = "Invalid phone or name, or missing Idempotency-Key")
    @APIResponse(responseCode = "409", description = "An active customer has this phone, or the same request is still running")
    public CustomerResource register(@HeaderParam("Idempotency-Key") UUID idempotencyKey,
                                     @Valid RegisterCustomerResource resource) {
        var command = RegisterCustomerCommandFromResourceAssembler.toCommandFromResource(
                tenantContext.organizationId(), idempotencyKey, resource);
        return CustomerResourceFromEntityAssembler.toResourceFromEntity(customerCommandService.handle(command));
    }

    @GET
    @Path("/{customerId}")
    @Operation(summary = "Get customer by id")
    @APIResponse(responseCode = "200", description = "Customer found",
            content = @Content(schema = @Schema(implementation = CustomerResource.class)))
    @APIResponse(responseCode = "404", description = "Customer not found in the organization")
    public CustomerResource getCustomerById(@PathParam("customerId") UUID customerId) {
        var id = new CustomerId(customerId);
        var customer = customerQueryService.handle(new GetCustomerByIdQuery(tenantContext.organizationId(), id))
                .orElseThrow(() -> new CustomerNotFoundException(id));
        return CustomerResourceFromEntityAssembler.toResourceFromEntity(customer);
    }

    @DELETE
    @Path("/{customerId}")
    @ResponseStatus(204)
    @Operation(summary = "Delete customer", description = "Soft-deletes the customer; the phone can be registered again.")
    @APIResponse(responseCode = "204", description = "Customer deleted")
    @APIResponse(responseCode = "403", description = "Role cannot delete customers")
    @APIResponse(responseCode = "404", description = "Customer not found in the organization")
    public void delete(@PathParam("customerId") UUID customerId) {
        customerCommandService.handle(new DeleteCustomerCommand(tenantContext.organizationId(), new CustomerId(customerId)));
    }
}
```

## Tests

Domain tests are plain JUnit: no `@QuarkusTest`, no database.

```java
package com.takodu.api.customers.domain.model.aggregates;

class CustomerTest {
    private final OrganizationId organization = new OrganizationId(UUID.randomUUID());

    @Test
    void deletingADeletedCustomerIsRefused() {
```

Endpoint tests use `@QuarkusTest` (Dev Services starts PostgreSQL in Docker) and assert the status and the error `code`. `TestTenants` in `src/test/java/com/takodu/api/shared/testing` creates a user, an organization and a membership with the given role and returns an authenticated request specification with `X-Organization-Id`.

```java
package com.takodu.api.customers.interfaces.rest;

@QuarkusTest
class CustomersControllerTest {
    @Test
    void retryWithTheSameKeyReturnsTheSameCustomer() {
```
